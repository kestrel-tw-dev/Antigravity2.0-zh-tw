## 為什麼選擇這套中文化？

- **超級快速簡便，點兩下 `Start.bat` 就好**  
  純英文啟動鍵設計，徹底杜絕舊系統與壓縮檔檔名亂碼；不需要安裝 Node.js、不卡視窗等待按鍵，開著 Antigravity 時也能直接點——程式會自動幫您關掉舊視窗、秒速完成中文化，自動收掉黑框並重新打開中文版。
- **Google Carbon High（深度思考・高）高精準翻譯**  
  全面校對介面按鈕、選單、設定說明、技能（Skills）、外掛（Plugins）與操作提示；同時自動保護程式碼、終端機和編輯器內容不被誤翻，看得懂又不影響寫程式。
- **繁體中文 ＆ 簡體中文通通支援**  
  內建完整繁簡雙語字庫（各約 5,900+ 條對應），安裝時會自動偵測您的電腦語系，繁體電腦自動變繁中、簡體電腦自動變簡中。
- **官方更新後會自動翻譯（幾乎無感）**  
  以後軟體跳出更新時，只要放心點擊 **「重新啟動以更新」**，新版裝完會自動幫您補回中文再開啟，不必每次更新都重裝一次中文化。

## 三步驟超簡單安裝

1. **下載成品壓縮包**：前往右側 [**Releases**](https://github.com/kestrel-tw-dev/Antigravity2.0-zh-tw/releases/latest) 頁面，或點擊直接下載最新版 [**`Antigravity2.0-zh-tw-v2.35.2.zip`**](https://github.com/kestrel-tw-dev/Antigravity2.0-zh-tw/releases/latest/download/Antigravity2.0-zh-tw-v2.35.2.zip) 並解壓縮到任意位置。
2. **點兩下打開** **`Start.bat`**。
3. **等約 1～2 秒鐘**，視窗會自動完成中文化、打開 **中文版 Antigravity** 並直接關閉黑框！

## 常見問題

**Q：我的電腦是簡體／繁體系統，但我想手動切換另一種中文怎麼辦？**  
A：打開資料夾內的命令提示字元執行即可：
- 強制改用繁體中文：`Start.bat --tw`
- 強制改用簡體中文：`Start.bat --cn`

**Q：想還原回官方英文原版怎麼辦？**  
A：執行 `Start.bat --restore`，就會無損恢復官方原版並清理自動更新守衛。
